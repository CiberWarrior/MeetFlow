# PDF fonts

`NotoSans-Regular.ttf` and `NotoSans-Bold.ttf` are from [Google Noto Fonts](https://github.com/googlefonts/noto-fonts), licensed under the SIL Open Font License.

They are used by the registration proforma PDF so Croatian characters (č, ć, š, ž, đ) render correctly. jsPDF's built-in Helvetica does not support them.
